# Behind the Fire Entries

This directory contains the source Markdown for Behind the Fire website entries.

Each entry explains creative inspiration around an original Campfire Horror Tale without presenting that fiction as a true account. Pair each Markdown entry with a small static HTML reader page that uses `data-behind-fire-source`, following `behind-the-fire-the-old-woman-in-the-mirror.html`.

Use front matter for the entry title, related story, publication status, and language. Keep image files in `assets/behind-the-fire/<entry-slug>/` when they are approved; add credits and captions in the entry Markdown. Do not create artwork or expand author reflections without approved source material.
